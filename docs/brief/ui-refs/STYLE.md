# Ice-lab

Cool paper grey **#E9EEF2**, graphite **#14181C** for type and the reflex trace, ultramarine **#2447F9** for the LLM ship, signal orange **#FF5A1F** for teacher pulses and rule flips. Instrument Sans provides text and wordmark. Martian Mono is for counters and axes.

Use a wide two-ship stage, a full-width two-lane who-drives trace, and a thin latency, handoff, and answer-rate rail. Use a card grid for results. Thin borders and small labels leave room for the data. On narrow and portrait screens, move telemetry below the side-by-side stage. README media uses only black, white, and greys.
