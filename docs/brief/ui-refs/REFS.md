# Ice-lab references

Sebastian's [Pinterest board](https://www.pinterest.com/roda0050/ui/) supplied four layout references.

- Urban noise monitoring. The dense heatmap and device panel inspired the one-column-per-frame who-drives display. [Image](https://i.pinimg.com/736x/3a/1e/bb/3a1ebbb53fe219f0ca8545932b26c35a.jpg)
- System performance monitor. The compact column of individually labeled real-time counters inspired the telemetry rail. [Image](https://i.pinimg.com/736x/d6/f8/b6/d6f8b6c2bccef1b64bb85aed46828f1b.jpg)
- Dot-matrix scatter. Use sparse points on a precise grid for calibration and agreement. [Image](https://i.pinimg.com/736x/1f/a8/04/1fa8048145baa0310b7d2b8e6deafe91.jpg)
- Light file-card layout. Use independent, aligned results cards in a grid. [Image](https://i.pinimg.com/736x/72/89/f5/7289f53657676a199a3d4744951a6827.jpg)
